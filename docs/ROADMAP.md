# Negotium 로드맵

비 IT 한국 중소기업이 **자기 서버, 자기 파일** 위에서 오피스워크를 AI로 돌리게 한다 —
이 목표를 기준으로 완료된 것과 앞으로 만들 것을 정리합니다.

## 완료 (2026-07 기준)

### 오피스 코어 루프
- **회의록 → 업무 배정**: 회의 메모에서 액션 아이템을 추출해 담당자·순서·의존성이 붙은
  업무로 자동 등록. 어떤 마크다운이든 순서·의존성 있는 업무 단계로 변환하는 스텝 엔진 공유.
- **업무 현황 → 주간보고**: 일정·병목·최근 기록을 모아 관리자용 보고서 생성.
- **인수인계**: 담당자의 활동 기록을 모아 인수인계 문서 생성 + 후속 업무 자동 배정.
- **채용/면접**: 부서·직급 컨텍스트를 반영한 직무 요구사항·면접 키트·온보딩 계획.

### Solar 에이전트 루프
- `solar-pro3` 도구 호출(병렬) 기반 AI 어시스턴트와 대화형 셋업 마법사.
- 읽기 도구 자동 실행 / 쓰기 도구 승인 카드, 승인은 내용 해시로 검증하고 재추론 없이 재생.
- 모델 티어 카탈로그(에이전트형/추론형/일반형)와 티어별 기능 제한 안내.

### 문서 파이프라인
- **HWP·HWPX·DOCX 첨부**: 클라우드 라우트는 Upstage Document Parse(표·서식 → 마크다운,
  파일별 캐시), 로컬 라우트는 순수 파이썬 내장 파서(zip+XML, OLE) — 파일이 외부로 안 나감.
- PDF·이미지(OCR)·엑셀 첨부, 출력 형식 지시자(markdown/html/csv/json/text).

### 자동화
- 분 단위 스케줄러: 주간보고 자동 생성(요일·시각, KST), 마감 초과·당일·정체 업무 리마인더.
- 인앱 알림함(🔔) + 슬랙 incoming webhook 호환 아웃바운드.

### 아카이브 검색
- 청크 단위 BM25 + 한국어 문자 2-gram 색인(조사 붙은 질의도 매칭), 증분 재색인.
- 옵트인 Upstage 임베딩 시맨틱 검색(RRF 융합) — 방화벽 통과 청크만 전송.

### 보안·운영
- PBKDF2 + 슬라이딩 세션 토큰, 로그인 스로틀링, 직급 기반 접근 제어, 계정 신청·승인.
- 컨텍스트 방화벽: 외부로 나가는 컨텍스트의 비밀키·PII 마스킹, 민감 등급별 로컬 강제/차단, 감사 기록.
- `archive/` 자동 git 백업(중첩 저장소, secrets 제외, 옵트인 원격 push).
- 감사 로그(append-only), 상태 초기화 CLI, Docker 배포.

## 다음 (단기)

- **업종별 온보딩 템플릿 + 데모 데이터**: 제조/유통/서비스 샘플 회사(회의록·조직·업무)를
  한 번에 심는 데모 모드 — 빈 콘솔이 아닌 "돌아가는 회사"로 첫인상을 만든다.
- **결재(승인) 흐름**: 생성 문서·업무 배정에 상신→검토→승인 단계를 붙여 한국 기업의
  결재 문화에 맞춘다. 승인 이력은 감사 로그와 archive git 이력에 연결.
- **생성 문서 품질 피드백 루프**: 문서별 👍/👎 + 사유 수집 → 작업 라우트·프롬프트 개선의
  근거 데이터로 축적.
- **이메일/그룹웨어 인제스트**: 메일·그룹웨어에서 회의 메모/업무 요청을 받아 코어 루프의
  입구를 넓힌다.

## 이후 (중기)

- **HWP·Excel·PPT 실파일 출력**: 지금은 markdown/html/csv 출력 — 한국 기업이 실제로
  주고받는 바이너리 형식으로 내보내기.
- **업무 자동 실행 에이전트 확대**: 계획 전용 → 승인 실행 → 정책 기반 자동 실행의 단계적
  확장. 스케줄된 업무 단계에 스킬을 붙여 사람 개입 없이 진행되는 범위를 넓힌다.
- **카카오워크 네이티브 연동**: 현재 웹훅 수준을 넘어 봇 대화로 업무 조회·승인까지.
- **모바일 대응**: 알림 확인·승인 등 이동 중 액션에 맞춘 반응형 콘솔.
- **조직별 메모리 스키마 고도화**: 회사마다 다른 영구 메모리 타입·필드의 셀프서비스 설계.
- **멀티 워커 배포**: 인메모리 상태(스로틀러·검색 포스팅)를 파일/공유 스토어로 옮겨
  다중 프로세스 배포 지원.

## 설계 원칙 (변하지 않는 것)

1. **DB 없음** — `archive/`의 md/json이 단일 진실 원본. 파생물은 언제나 재생성 가능한 캐시.
2. **프라이버시 기본값** — 외부로 나가는 모든 것은 방화벽을 통과하고, 민감한 것은 로컬에 남는다.
3. **비 IT 사용자 우선** — 키가 없어도, GPU가 없어도 콘솔은 열리고 안내로 대체된다.
